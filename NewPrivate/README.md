# Innova Product Catalog Frontend

A complete responsive catalog frontend based on the supplied visual reference.

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Included
- Responsive desktop/tablet/mobile layout
- Sticky navigation and mobile menu
- Hero carousel
- Category browsing
- Product catalog with search
- Category and price filtering
- Sorting
- Grid/list view
- Favorites
- Product detail modal
- Featured product detail section
- Enquiry list drawer
- Quantity controls
- Contact/newsletter demo actions
- No backend required

## Customize
Edit the `products` array in `app.js` to add/change products.
Change colors, spacing and breakpoints in `styles.css`.
Replace the Unsplash image URLs with your own product/brand images.
